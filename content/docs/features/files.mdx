Files gives your workspace a shared place to store documents, images, exports, and other assets — accessible to all workspace members.

## Open Files

Click **Files** in the left sidebar to open the Files page.

## File storage

File storage is coming to Clave. The Files section is your workspace's home for shared assets and will support uploading, organizing, and linking files to projects and issues.

When available, you'll be able to:

- **Upload files** directly from your computer
- **Preview** common file types (images, PDFs, videos) without downloading
- **Link files** to projects and issues so they're easy to find in context
- **Organize** files by project, type, or upload date
- **Share** files with anyone via a link

## Files in issues and projects

While the standalone Files page is coming soon, you can already attach files to issues today. When creating or editing an issue, use the **Attachments** section to upload files. They are stored and accessible from the issue detail view.

Project resources can also include links to external files and assets — see [Project Resources](/docs/features/projects/project-dashboard) for details.

## File types

Clave will support all common file types including:

- Images (PNG, JPG, GIF, SVG, WebP)
- Documents (PDF, DOCX, XLSX, PPTX)
- Video and audio files
- Archives (ZIP, TAR)
- Code files and text files

## Storage limits

File storage limits depend on your workspace's plan. See [Billing](/docs/settings/billing) for details on storage quotas by plan.
