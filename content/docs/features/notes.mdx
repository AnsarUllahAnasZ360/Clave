title: Notes
description: Capture lightweight notes at the workspace level.
---

Notes is a shared scratchpad for your workspace. Use it for quick thoughts, meeting agendas, team announcements, or any content that doesn't need the full structure of a document.

## Open Notes

Click **Notes** in the left sidebar. The Notes editor opens directly — there's no list view or file picker.

## Writing in Notes

Notes uses a block-based editor. Click anywhere in the editor area and start typing.

You can use familiar keyboard shortcuts for basic formatting:

- `#` followed by a space → Heading 1
- `##` followed by a space → Heading 2
- `###` followed by a space → Heading 3
- `-` followed by a space → Bulleted list
- `1.` followed by a space → Numbered list
- `[]` followed by a space → To-do checkbox
- ` ``` ` → Code block
- `>` followed by a space → Blockquote

Type `/` to open the slash command menu for more block types.

## Notes vs. Documents

Both Notes and Documents support rich text editing. Here's when to use each:

| | Notes | Documents |
|---|---|---|
| **Best for** | Quick team notes, scratch content | Long-form, structured content |
| **Scope** | One shared workspace-level page | Many individual documents |
| **Organization** | Single note per workspace | Organized, filterable list |
| **Collaboration** | Shared workspace note | Full real-time multi-user editing |
| **Comments** | — | Threaded inline comments |
| **Sharing** | Workspace members only | Public share links available |

Use **Notes** when you need a quick shared scratch pad. Use **Documents** when you need separate, organized pages with titles, cover images, and comment threads.

## Saving

Notes save automatically as you type. There is no save button.

## Workspace notes

Notes are shared across all workspace members. Anyone in the workspace can read and edit the notes page. There is one notes page per workspace.
