Sprints help you plan work in focused time-boxed cycles. Within a project, you can create multiple sprints, assign issues to them, and track progress over time.

## What are sprints?

A sprint is a defined period of work — for example, "Sprint 1: Jan 6–Jan 17". Each sprint has a name, optional description, a start date, and a target end date. Issues assigned to a sprint appear together in the sprint view, making it easy to see what the team is working on right now.

Sprints are available on projects that use the **Sprints** methodology. You can set this when creating the project or change it later in the project settings.

## Creating a sprint

1. Open your project from the sidebar or projects list.
2. In the project header area, look for the **Sprints** section in the sidebar or the sprint panel.
3. Click **New sprint** to open the sprint creation form.
4. Enter the sprint name (required), an optional description, and set start and target dates using the date pickers.
5. Click **Create** to save.

## Sprint fields

| Field | Description |
|-------|-------------|
| **Name** | The sprint's display name. Required. |
| **Description** | Optional context about the sprint's goals. |
| **Start date** | When the sprint begins. |
| **Target date** | The planned end date for the sprint. |

## Editing a sprint

1. Find the sprint in the project's sprint list.
2. Click the three-dot menu or the sprint name to open edit options.
3. Select **Edit sprint** to open the edit dialog.
4. Update the name, description, or dates and click **Save changes**.

## Assigning issues to sprints

You can assign an issue to a sprint in several places:

- **When creating an issue** — In the full issue creation modal, select a project first, then choose the sprint from the Sprint picker in the properties panel.
- **From the issue detail page** — In the properties sidebar on the right, click the **Sprint** field and select a sprint.
- **From the board or list view** — Click on an issue to open the properties panel and update the sprint there.

## Sprint progress

Once issues are assigned to a sprint, you can see progress in the sprint panel. The sprint shows:

- How many issues are complete vs. total
- Issue status breakdown within the sprint
- Which issues are blocked or overdue

## Removing an issue from a sprint

Open the issue detail page and click the **Sprint** field in the properties sidebar. Select a different sprint or clear the sprint assignment to move the issue back to the backlog.
