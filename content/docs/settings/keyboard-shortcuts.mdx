---
title: Keyboard shortcuts
description: A complete reference for Clave's keyboard shortcuts.
---

Clave is built for keyboard-first workflows. Most actions can be performed without reaching for the mouse. Press **?** anywhere in the app to open the interactive shortcuts overlay.

## Global shortcuts

These shortcuts work from anywhere in the app (when you're not typing in a text field).

| Shortcut | Action |
|----------|--------|
| C | Create issue |
| V | Full-screen issue create |
| ? | Show keyboard shortcuts overlay |
| / | Search |
| Cmd+K | Open command palette |
| Cmd+B | Toggle sidebar |

## Navigation

Use these to jump between sections instantly.

| Shortcut | Action |
|----------|--------|
| G then I | Go to Inbox |
| G then T | Go to Tasks |
| G then P | Go to Projects |
| G then D | Go to Docs |
| G then B | Go to Boards |
| G then C | Go to Clients |
| G then S | Go to Settings |
| J or ↓ | Move selection down |
| K or ↑ | Move selection up |
| Enter | Open selected item |
| Space | Peek issue preview |

## Issue actions

These shortcuts apply when an issue is selected in a list, board, or inbox preview panel.

| Shortcut | Action |
|----------|--------|
| S | Set status |
| A | Set assignee |
| P | Set priority |
| L | Set labels |
| Shift+M | Set sprint |
| Shift+P | Set project |

## Inbox shortcuts

| Shortcut | Action |
|----------|--------|
| J or ↓ | Move selection down |
| K or ↑ | Move selection up |
| U | Toggle read/unread |
| Alt+U | Mark all read |
| H | Snooze 1 hour |
| E | Archive |
| Backspace | Delete selected notification |
| Shift+Backspace | Delete all visible notifications |
| Cmd+D | Delete all read notifications |
| Cmd+F | Focus search |

## Views

| Shortcut | Action |
|----------|--------|
| Shift+V | Open display options |
| F | Open filter |

## AI shortcuts

| Shortcut | Action |
|----------|--------|
| Cmd+J | Toggle AI chat sidebar |
| Cmd+N | Start a new AI chat thread |
| Cmd+/ | Focus chat input |
| Cmd+I | Inline AI prompt (in document editor) |
| Cmd+Shift+A | AI action menu |
| Cmd+Shift+V | Toggle voice dictation |
| Escape | Close or dismiss AI panel |

## Shortcut overlay

Press **?** at any time to open the full shortcuts overlay. The overlay groups all shortcuts by category and shows the keyboard combination for each. It's searchable and always up to date.

> On Windows and Linux, **Cmd** is replaced by **Ctrl** throughout.
