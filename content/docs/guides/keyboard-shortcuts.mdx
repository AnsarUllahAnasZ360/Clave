## Overview

Clave supports extensive keyboard shortcuts to help you navigate and work faster. Press `?` at any time to open the shortcuts menu.

## Navigation

Use `G` followed by a second key to jump between sections:

| Shortcut | Action |
|---|---|
| `G` then `P` | Go to Projects |
| `G` then `T` | Go to Tasks |
| `G` then `D` | Go to Docs |
| `G` then `B` | Go to Boards |
| `G` then `I` | Go to Inbox |
| `G` then `C` | Go to Clients |
| `G` then `S` | Go to Settings |

## Issue management

| Shortcut | Action |
|---|---|
| `C` | Create new issue |
| `1`–`6` | Set status (Backlog → Done → Cancelled) |
| `P` then `0`–`4` | Set priority (None → Urgent) |
| `L` | Open label picker |
| `A` | Open assignee picker |
| `E` | Archive issue |

## General

| Shortcut | Action |
|---|---|
| `Cmd+K` | Open command palette |
| `Cmd+B` | Toggle sidebar |
| `Cmd+J` | Open AI chat |
| `?` | Toggle shortcuts menu |
| `Escape` | Close dialogs and overlays |

## Tips

- **Chord shortcuts** (like `G` then `P`) require pressing the keys in sequence, not simultaneously
- Shortcuts are disabled when typing in text inputs, editors, or textareas
- The command palette (`Cmd+K`) provides fuzzy search across all actions
