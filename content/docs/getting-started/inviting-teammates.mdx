## How inviting works in Clave

Clave uses invite codes to bring people in. There are two levels:

- **Organization invite codes** — Let someone join the organization itself.
- **Workspace invite codes** — Let an organization member join a specific workspace.

Most of the time you will start with an organization invite, then add people to specific workspaces as needed.

## Generate an organization invite code

You need to be an **admin** or **owner** of the organization to create invite codes.

1. Go to **Organization Settings** by clicking the organization name and selecting **Settings**.
2. Select the **Invite codes** tab.
3. Click **Generate invite code**.
4. Copy the 6-character code that appears.

Share the code with your teammate. They can enter it on the **Organizations** page by clicking **Join**.

![Organization invite codes screen](/docs/screenshots/org-invite-codes.png)

## Invite code options

When generating a workspace invite code, you can set optional limits:

| Option | Description |
|--------|-------------|
| **Max uses** | The code expires once it has been used this many times. Leave blank for unlimited. |
| **Expiration** | Set a time limit (e.g., 24 hours, 7 days). Leave blank to never expire. |

Organization-level codes work similarly.

## How a teammate joins

When someone receives an invite code:

### Joining an organization

1. Sign in to Clave (or create an account — see [Signing up](/docs/getting-started/signing-up)).
2. On the **Organizations** page, click **Join**.
3. Enter the invite code in the dialog.
4. The organization name appears as a preview — click **Join organization** to confirm.

They are added to the workspace and can start collaborating immediately.

## Manage members

### Organization members

In **Organization Settings → Members**, you can:

- See all members and their roles (owner, admin, member).
- Remove members from the organization.

### Workspace members

In **Workspace Settings → Members**, you can:

- See all members in the workspace.
- Add or remove members.
- Change member roles within the workspace.

## Remove a member

To remove someone from an organization, go to **Organization Settings → Members**, find their name, and select **Remove**. They lose access to all workspaces in the organization.

To remove someone from a specific workspace only, go to **Workspace Settings → Members** and remove them there.
